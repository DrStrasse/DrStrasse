## Shortcuts

| Shortcut           | Description                               |
| ------------------ | ----------------------------------------- |
| Ctrl+Space         | Validate (and move cursor to error)       |
| Ctrl+S             | Save                                      |
| Ctrl+Q             | Close Editor                              |
| Ctrl+Z             | Undo                                      |
| Ctrl+Y             | Redo                                      |
| Ctrl+X             | Cut                                       |
| Ctrl+C             | Copy                                      |
| Ctrl+V             | Paste                                     |
| Ctrl+A             | Select all                                |
| Ctrl+I / Tab       | Indent                                    |
| Ctrl+O / Shift+Tab | Outdent                                   |
| Ctrl+K             | Comment selected block                    |
| Ctrl+Shift+K       | Uncomment selected block                  |
| Ctrl+F             | Find text                                 |
| Ctrl+H             | Find+Replace text                         |
| Ctrl+Up            | Scroll up                                 |
| Ctrl+Down          | Scroll Down                               |
| Ctrl+Left          | Scroll Left                               |
| Ctrl+Right         | Scroll Right                              |
| Ctrl+Home          | Go to first line                          |
| Ctrl+End           | Go to last line                           |
| Ctrl+D             | Duplicate line                            |
| Ctrl+Backspace     | Remove previous word                      |
| Ctrl+L             | Remove and copy current line              |
