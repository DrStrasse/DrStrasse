# Ядро Цитадели (citadel_core) — реактор тёмной энергии HL2

Два чипа на чистом дефолтном Wiremod (propcore **не** нужен):

| Файл | Что делает |
|---|---|
| `citadel_core.txt` | Само ядро: выработка энергии, пульсирующая голограмма-сфера, спутники и кольцо, перегрузка/критика/коллапс, EGP-панель, звук, чат-команды, рассылка состояния в «сеть» |
| `citadel_power_relay.txt` | Пример потребителя: принимает `citadel_grid` и отдаёт `Power` (лампы/двери/что угодно живут только пока ядро в норме) |

## Установка

1. Скопируй оба `.txt` в `garrysmod/data/expression2/citadel/`
   (или прямо в `expression2/` — тогда без подпапки).
2. В игре: тул **Wire → Expression 2** → выбрать файл → ЛКМ.

Сам чип выглядит как `models/props_combine/coreball.mdl`; вокруг него —
голографическая оболочка (ядро, свечение, два спутника, кольцо).

## Быстрый старт

1. Поставь `citadel_core` (оригинально ядро висит в воздухе — подложи базу
   или завари к платформе).
2. Запусти: нажми **E** на чипе или `!core on` в чат.
3. Ядро пройдёт стадию BOOTING (~3 с) и выйдет на ONLINE:
   - `Power = 1`, энергия копится до 1000;
   - `!core status` — телеметрия.
4. Потребители: подключи проводом `Power` чипа к лампам, либо поставь
   `citadel_power_relay` рядом и бери питание уже с него (работает без
   проводов, через remote-протокол).

## Электросеть и нагрузка

- Вход `Load` = суммарная нагрузка сети. `!core load 130` — симулировать
  нагрузку без проводов.
- Если `Load + LoadManual + BaseLoad > Gen` → **OVERLOAD**: стабильность
  падает, свечение янтарное, пульс учащается.
- `Boost` (вход) = форсаж ×1.5 выработки ценой стабильности.
- Стабильность < 25 → **CRITICAL**: 15 с на спасение (кнопка на входе
  `Stabilize` или `!core stabilize` — жрёт 10% энергии). Не успел —
  **КОЛЛАПС**: вспышка, взрыв, ядро мертво 8 с, потом можно запустить снова.
- Энергия кончилась → **BLACKOUT**: сеть без напряжения до восстановления
  заряда ≥ 5%.

## EGP-панель (опционально)

Поставь **EGP Screen/Emitter/HUD** и подключи его `wirelink` к входу
`Screen` чипа. На экране — статус, заряд, стабильность, баланс сети.
Если заменил экран — напиши `!core redraw`.

## Команды чата (владелец)

`!core on` `!core off` `!core status` `!core rate 0-150` `!core load 0-500`
`!core stabilize` `!core mute` `!core scale 1-12` `!core redraw` `!core help`

## Тюнинг

Все константы баланса (`Capacity`, `BootRate`, `MaxGen`, `MeltdownT`…) —
в шапке чипа с комментариями. Размер оболочки: `!core scale`.
