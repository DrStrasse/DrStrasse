# RAIL CORE — ядро-диспетчер железной дороги

Система из трёх чипов (дефолтный Wiremod, propcore не нужен). Поезда и пути
строишь сам из пропов; чипы дают автоматику, датчики, светофоры и связь.

| Файл | Роль |
|---|---|
| `rail_core.txt` | **Ядро-диспетчер** (мозг): 4 блок-участка, 3-значная автоблокировка, ручной режим по numpad, аварийный стоп, ETA, EGP-пульт, радио-рассылка `rail_grid` |
| `rail_signal.txt` | **Светофор + датчик**: луч поперёк пути чувствует поезда (Occupied), цвет по проводу (Aspect) или по радио; лампы + голограмма-огонёк |
| `rail_train.txt` | **Звено поезда**: принимает от ядра разрешение (`Run`, `MaxSpeed`), собственный «глаз» препятствий впереди, аварийный стоп при потере связи |

## Логика (автоматика)

- Блок занят → сигнал блока **красный**, предыдущего — **жёлтый**,
  свободные — **зелёные** (классика 3-значной АБ).
- `Emergency` / `!rail estop` / потеря ядра → **всё в красный**, поезда встают.
- Ядро выключено → все сигналы красные (безопасность по умолчанию).
- ETA = длина блока / скорость (вход `TrainSpeed`, длина — `!rail blocklen`).

## Топология A — по радио (ноль проводов)

1. Поставь `rail_core`, напиши `!rail on`.
2. Расставь `rail_signal` вдоль путей (правый бок чипа — вдоль пути!),
   каждому: `!sig block 1` … `!sig block 4`.
3. На поезд поставь `rail_train` (носом по ходу!): `!train block N`,
   подключи `Run` к тормозам/стопу и `MaxSpeed` к Force трaстера.

Готово: датчики сами сообщают занятость, ядро само переключает светофоры,
поезда сами подчиняются.

## Топология B — по проводам

- светофор.`Occupied` → ядро.`Occ1`..`Occ4`
- ядро.`S1`..`S4` → светофор.`Aspect` → лампы берутся с `Red/Yellow/Green`
- кнопка/тумблер → ядро.`Emergency`; провод → `Auto` (ручной/авто)
- `TrainSpeed` ← любой спидометр-приёмник
- Numpad Input → ядро.`Kb` (wirelink): клавиши 1..4 крутят аспекты вручную,
  0 — аварийный стоп
- EGP Screen → ядро.`Screen` — пульт диспетчера

## Ориентация чипов (важно!)

- `rail_signal`: луч датчика — в **правую** сторону чипа (`E:right()`),
  высота 20 юнитов. Встань так, чтобы правый бок смотрел вдоль колеи.
- `rail_train`: луч-глаз — **вперёд** (`E:forward()`), высота 15.
  При варке на поезд чип поворачивается вместе с ним — это нормально.
  Чип и вагон сварки из луча исключены автоматически.

## Чат-команды

- Ядро: `!rail on off status auto estop reset blocklen N mute redraw help`
- Светофор: `!sig block 1-4`, `!sig status`, `!sig mute`
- Поезд: `!train block 1-4`, `!train status`

## Выходы поезда для подключения к твоим проповым составам

`Run` (0/1) — «едь», `MaxSpeed` (100/40/0) — сила трaстера, `Obstacle` —
стоп-кран, `Alarm` — авария, `Dist` — дистанция до препятствия, `Block` —
номер своего блока.
