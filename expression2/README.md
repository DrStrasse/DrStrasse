# Чипы Expression 2

Здесь живут исходники чипов (`.txt`). Вложенные папки соответствуют папкам
в игровом E2-редакторе.

## Установка в игру

Скопировать нужный `.txt` в:

```
GarrysMod/garrysmod/data/expression2/
```

Дальше: в игре → тул **Wire → Expression 2** → выбрать файл → ЛКМ ставит чип.

## Правила оформления

- `@strict` — всегда; `@name` — осмысленное; комментарии — на русском.
- Современный стиль: `event ... {}` вместо `runOn*`/`xxxClk`,
  `timer(секунды, function() {})` вместо легаси-таймеров, `let/const`.
- Тяжёлые предметы (find, holoCreate, file, http) — с проверками
  `findCanQuery()/holoCanCreate()/fileCanLoad()` и без спама в тик.
- Если чип требует расширение (propcore и т.п.) — `#ifdef`-проверка
  и `#error`-сообщение в шапке.

`_template.txt` — отправная точка: скопируй и переименуй.
