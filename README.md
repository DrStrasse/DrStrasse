# GRM — RolePlay Addon для Garry's Mod

Полнофункциональный аддон для roleplay-серверов Garry's Mod: фракции, экономика,
документы, служебные компьютеры, розыск и штрафы, транспорт, логистика, маскировка,
комендантский час, CCTV, прослушка, пожарная служба и многое другое.

Этот репозиторий содержит только проект (без черновиков, аналитики и мусора).

## Состав

| Путь | Что это |
|---|---|
| `lua/` | Основной код аддона (авторан-скрипты, энтити, оружие, тулзы) |
| `materials/` | Материалы (интерфейс, оверлеи, текстуры) |
| `models/` | Модели |
| `addons/grm_fire/` | Отдельный пожарный аддон (vFire, рукава, гидранты, насосы) |
| `tools/` | Скрипты сборки (`build_dist.py`) и luatest-симуляции |
| `dist/` | Готовые архивы для установки |

## Установка

Основной аддон кладётся в `garrysmod/addons/grm/` (архив `dist/grm_single_addon.zip`
уже содержит префикс `grm/`), пожарный — в `garrysmod/addons/grm_fire/`
(`dist/grm_fire_addon.zip`).

## Сборка архивов

```bash
python3 tools/build_dist.py
```

Собирает в `dist/`:
- `grm_single_addon.zip` — единый аддон со всеми модулями;
- `grm_full_code.zip` — полный исходный код;
- `grm_economy.zip` — изолированный экономический срез;
- `grm_fix_hud_tab_currency.zip` — точечный патч интерфейса и валюты;
- `grm_fire_addon.zip` — пожарный контент-аддон.

## Ключевые системы

- **Фракции** — создание организаций, должности, отделы/подотделы, казна,
  доступы по ролям, единый центр управления (Unified UI).
- **Экономика** — банки, банкоматы, терминалы, валюта, инкассация, документы.
- **Розыск и штрафы** — каталог статей, вменение нарушений, ориентировки.
- **Службы** — логистика, биржа труда, телефон, служебные компьютеры.
- **Спецслужбы** — маскировка, прослушка (RoomTap), CCTV, комендантский час.
- **Пожарная служба** — очаги, тушение, рукава, насосы, гидранты.
